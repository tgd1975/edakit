# RS Components (de.rs-online.com)

Order number: seven digits, shown as `221-5535`.

**No automated access.** Search, product pages and even robots.txt answer 403 to curl and WebFetch, and RS has no
self-service API – RS issues credentials only through its account managers, after signing its terms.

- A web search (`<MPN> site:rs-online.com`) can find the RS number; its snippets are no stock figure.
- Stock and price come from the user, who opens the page: ask for them, and report them as open until then – never
  as "in stock".
- The page states RoHS status, country of origin and discontinued notices.

If the user gets API credentials from RS, write how to use them here.
