# edakit circuit language for VS Code

Colours for `.circuit` files (the TextMate grammar generated by `python -m edakit.lang.grammar`), and the language
server `edakit lsp`: the reader's and the compiler's errors as you type, the findings of `edakit check` at the
statements they come from, go to definition (a pin word to its parts entry, a usage to its definition, a net to its
first statement), hover (a part's entry, a pin's number and role, a net's range), completion (pin words after `DES.`,
codes after `accept`, definitions after `use`) and formatting on save. Commands: `graph json --write`, `graph json
--check`, `graph show` for the word under the cursor, `graph fmt`; the two graph commands also as tasks.

Needs edakit with its extra `lsp` (pygls): `uv tool install 'edakit[lsp]'`, or the setting `edakit.command` naming the
executable. Not published to the marketplace; install from a package built here:

```bash
npm ci && npm run compile && npx @vscode/vsce package
code --install-extension edakit-circuit-0.1.0.vsix
```
